# fuly圣诞树

圣诞树产品展厅与管理员后台。前台路径 `/`，产品详情 `/products/:id`，管理后台 `/admin`。

## 已实现
- 商品卡片与独立详情页；产品名称、型号、系列、高度、宽度、材质和灯光配置。
- 高清多图上传与封面选择，鼠标悬停 2.5 倍独立放大窗口、可滚动大图弹窗和移动端布局。
- 后台搜索、状态筛选、新增、编辑、删除、上下架、排序。
- D1 保存产品，R2 保存原始图片。支持 JPG、PNG、WebP；每张上限 10 MB，每件产品最多 10 张。
- ChatGPT 登录识别管理员；服务端权限检查与来源校验保护修改接口。

## 管理员
线上环境使用 `ADMIN_EMAIL` 引导首次管理员绑定，随后以站点稳定用户 ID 校验。环境变量通过 Sites 设置，不提交到源代码。
本地开发使用 starter 提供的 loopback 模拟登录，身份为 `local_seedy`，不会包含在生产构建。

## 本地运行
Node.js >= 22.13，npm ci，npm run dev。
需要先生成、构建并应用 D1 本地迁移，详见生成的 `drizzle/` 和 `dist/server/wrangler.json`。当前工作区的本地迁移已应用，请勿重复执行。

## 示例数据
首次加载写入三款明确标记为示例的产品，仅写入一次。删除后不会自动恢复。图片由 AI 生成，规格用于演示，正式对客展示前请用实际产品信息替换。

## 验证
已通过 TypeScript 检查及生产构建。自动化接口检查覆盖匿名拒绝、跨来源拒绝、上传与读取、创建、数值校验、重复型号、编辑、持久读取、上架、下架、删除及未公开详情的 404。
